# 产品需求与首版边界

## 1. 产品定位

“个人支撑材料编排器”（SupportPackBuilder）面向高校教师、科研人员、专业技术人员和行政人员。用户按两级目录整理 PDF、图片与 Office 文档，最终生成正式、统一、可校验的 A4 PDF。

产品必须完全本地运行，不上传用户文件，不依赖远程后端、账号、AI 或云服务。

## 2. 核心用户流程

1. 新建项目并填写项目名称、姓名、单位、用途和编制日期。
2. 选择内置模板或空白模板，建立一级目录、二级目录。
3. 选择、批量选择、拖入文件或文件夹。
4. 检查扩展名、真实 MIME、权限、哈希、页数、加密状态、图片尺寸、OOXML 结构和重复项。
5. 在本机将 DOCX、PPTX、XLSX 转为经过校验的 PDF 快照。
6. 将图片分别导入或合并为同一材料。
7. 调整目录、材料和材料内页面顺序。
8. 设置页码范围、旋转、删除、恢复、标题页和备注。
9. 按需把同一 PDF、多来源材料或多项成果的连续页面组合成自主可控的 A4 多图拼版。
10. 使用最终页面缩略图核对物理顺序、拼版清晰度与逻辑页码。
11. 执行导出前检查，生成封面、目录、标题页、内容页和统一页码。
12. 重读输出 PDF 并查看自动校验报告。
13. 保存、重开、复制或通过 `.spack` 迁移项目。

## 3. 首版输入格式

- PDF
- JPG、JPEG
- PNG
- WebP
- DOCX
- PPTX
- XLSX

图片集合中的每张图片默认独占一个 A4 页面；用户可显式创建多图拼版，未参与拼版的页面仍保持独占。

## 4. 首版明确不支持

- DOC、PPT、XLS 旧格式
- DOCM、PPTM、XLSM 宏格式和密码 Office 文件
- OCR
- 云同步、用户登录、多人协作
- AI 自动识别和远程文件上传
- 电子签章、手写批注和 PDF 正文编辑

转换层通过适配器实现 LibreOffice OOXML 转换，后续可增加其他 Office 引擎和 OCR 适配器，但当前不提供模拟转换入口。

## 5. 项目与材料

项目采用 `schemaVersion: 3`，默认 copy 模式。项目内资产使用相对路径，reference 模式才允许外部绝对路径；Office PDF 快照始终保存在项目内。所有实体具有稳定 UUID。

目录层级严格为两级：

- 一级目录：材料大类。
- 二级目录：具体材料分组，材料只能挂载在二级目录。

材料记录来源类型、来源项、文件元数据、页数、页码范围、稳定页面 ID、页面顺序、旋转、删除状态、校验状态和时间戳。Office 来源额外记录格式、转换器版本、原件与快照哈希、快照路径、页数、时间和警告。原文件永不被修改。

## 6. 页面与目录

PagePlan 是预览、目录、自动编号和导出的唯一顺序数据源。它区分物理索引、用户页序、来源页索引、逻辑页码、打印页码和目录引用页码。

目录标题保存为不含序号的纯文本。仅启用且实际产生页面的材料和祖先目录参与输出：一级、二级、材料分别自动显示 `一、`、`（一）`、`1.`；空目录显示“未输出”，不占序号，也不进入 PDF 目录。拖拽、启停、删除和页面范围变化后必须重新派生。

项目属性与封面字段独立保存。新建项目时复制一次，之后封面缩略图和最终 PDF 只读取封面配置，项目属性修改不得回写。

输出顺序为：

1. 封面
2. 可选的封面背面空白页
3. 自动目录
4. 启用的独立分类标题页
5. 独立材料标题页
6. 材料内容页

参考 DOCX 样式下，分类和材料标题默认与首张内容页同页，不额外占用物理页；用户明确启用独立标题页后才生成单独页面。

目录包含有效一级、二级和材料条目；目录页数最多迭代 5 次。不稳定时阻止导出。预览必须使用真实稳定目录页数和最终显示文本，不允许 CSS 占位目录。

## 7. 自主可控多图拼版

拼版的目标是减少纸张，同时保持专家能够快速确认每一页的归属和内容。支持以下来源组合：

- 同一 PDF 的多个页面。
- 同一成果中的 PDF、图片、Office 快照等多个来源项。
- 图片集合、证书正反面、主体材料与附件、原图与局部细节。
- 多项成果之间的连续页面；每项成果使用独立全宽区段并显示标题。
- 经用户再次确认的跨二级目录页面。

系统提供上下两页、四宫格、证书 2×2、证书 2×3、正反面、主体＋附件、联系表、纵向长条和原图＋细节模板。模板只负责生成初始布局，用户可继续：

- 增删拼版页并调整 A4 横纵方向。
- 调整成果区段高度、区段间距、槽位间距和页边距。
- 横向或纵向拆分槽位、合并空槽、交换或移动来源页。
- 调整槽位比例、适配方式、九宫格对齐、90 度旋转和归一化裁切框。
- 使用保留安全余量的自动去白边，或恢复完整原图。
- 将同一来源显式复制为“原图＋细节”；普通重复页面不允许。

拼版配置保存在 `layoutSheets`，不生成或修改来源文件。只有 PagePlan 可以决定拼版替换了哪些普通内容页以及最终物理位置。页面选择必须在 canonical PagePlan 中连续；跨成果和跨目录操作需要明确确认。

自动建议受每页槽位上限和清晰度阈值约束。系统同时显示原始页数、拼版页数、节省页数和双面打印纸张估计。低于阻止阈值的槽位必须调整，或由用户逐槽确认清晰度风险后才能进入最终计划；自动生成的危险布局不能仅靠全局确认绕过。

缺失或删除的来源页在工作台中保留红色缺失槽，避免布局静默收缩；删除整项材料或目录时同步清理其拼版区段。任何自动建议都不得因模板容量静默截断来源页。

## 8. A4 与页码

所有最终物理页必须为 A4。默认 A4 纵向，保留 A4 横向输出设置。参考版式默认使用上下左右 36 point（约 12.7 mm）安全边距；同页标题占用顶部安全区，来源内容在剩余区域等比缩放、居中、不拉伸、默认不裁切。

页码支持底部居中和底部右侧，格式支持：

- `1`
- `— 1 —`
- `第 1 页`
- `1 / 50`

封面、目录可分别设置是否计入和显示；正文从用户指定数字开始，标题页属于正文。

## 9. 可靠性与错误

- 项目保存先写临时文件、刷新、Zod 重读，再原子替换并保留一代备份。
- 导出写同目录临时文件，重读校验后原子替换目标。
- 用户取消时停止后续页面，清理临时文件，不产生不完整目标。
- 缺失、加密、损坏、格式伪装、权限错误和非法页码范围不得静默忽略。
- 用户提示必须包含阶段、文件或材料、原因和建议；堆栈只写脱敏日志。
- 输出页面写入来源页 ID 数组和布局摘要标记；重读校验会检查拼版顺序、遗漏、重复、材料归属与 PagePlan 一致。

## 10. 性能目标

- 至少 300 个最终页面
- 输入文件合计至少 500 MB
- 缩略图按需加载和缓存
- 页面超出预览区时显示不受系统自动隐藏设置影响的常驻垂直滚动条
- Renderer 不持有大型二进制
- 后台导出期间 UI 保持可交互
- 大文件处理限制并发并支持取消
- Office 转换并发固定为 1，单文件超时 180 秒

性能数字是设计目标，只有实际执行过的范围才记录为已验证。

## 11. 发布边界

提供 macOS DMG 和 Windows NSIS 配置，随安装包包含对应平台的 LibreOffice 固定运行时和许可证。首版不要求签名和公证，但发布文档必须说明证书、Apple 公证和未签名应用警告。
