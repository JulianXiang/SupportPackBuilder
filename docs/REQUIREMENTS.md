# 产品需求与首版边界

## 1. 产品定位

“个人支撑材料编排器”（SupportPack Builder）面向高校教师、科研人员、专业技术人员和行政人员。用户按两级目录整理 PDF 与图片，最终生成正式、统一、可校验的 A4 PDF。

产品必须完全本地运行，不上传用户文件，不依赖远程后端、账号、AI 或云服务。

## 2. 核心用户流程

1. 新建项目并填写项目名称、姓名、单位、用途和编制日期。
2. 选择内置模板或空白模板，建立一级目录、二级目录。
3. 选择、批量选择、拖入文件或文件夹。
4. 检查扩展名、真实 MIME、权限、哈希、页数、加密状态、图片尺寸和重复项。
5. 将图片分别导入或合并为同一材料。
6. 调整目录、材料和材料内页面顺序。
7. 设置 PDF 页码范围、旋转、删除、恢复、标题页和备注。
8. 使用最终页面缩略图核对物理顺序与逻辑页码。
9. 执行导出前检查，生成封面、目录、标题页、内容页和统一页码。
10. 重读输出 PDF 并查看自动校验报告。
11. 保存、重开、复制或通过 `.spack` 迁移项目。

## 3. 首版输入格式

- PDF
- JPG、JPEG
- PNG
- WebP

图片集合中的每张图片默认独占一个 A4 页面。

## 4. 首版明确不支持

- DOCX、PPTX、XLSX 转换
- OCR
- 云同步、用户登录、多人协作
- AI 自动识别和远程文件上传
- 电子签章、手写批注和 PDF 正文编辑
- 一页多图拼版

转换层保留适配器职责，后续可增加 Office 和 OCR 适配器，但首版不提供模拟入口。

## 5. 项目与材料

项目采用 `schemaVersion: 1`，默认 copy 模式。项目内资产使用相对路径，reference 模式才允许外部绝对路径。所有实体具有稳定 UUID。

目录层级严格为两级：

- 一级目录：材料大类。
- 二级目录：具体材料分组，材料只能挂载在二级目录。

材料记录来源类型、来源项、文件元数据、页数、页码范围、稳定页面 ID、页面顺序、旋转、删除状态、校验状态和时间戳。原文件永不被修改。

## 6. 页面与目录

PagePlan 是预览、目录和导出的唯一顺序数据源。它区分物理索引、用户页序、来源页索引、逻辑页码、打印页码和目录引用页码。

输出顺序为：

1. 封面
2. 可选的封面背面空白页
3. 自动目录
4. 启用的独立分类标题页
5. 独立材料标题页
6. 材料内容页

参考 DOCX 样式下，分类和材料标题默认与首张内容页同页，不额外占用物理页；用户明确启用独立标题页后才生成单独页面。

目录包含一级、二级和材料条目；目录页数最多迭代 5 次。不稳定时阻止导出。

## 7. A4 与页码

所有最终物理页必须为 A4。默认 A4 纵向，保留 A4 横向输出设置。参考版式默认使用上下左右 36 point（约 12.7 mm）安全边距；同页标题占用顶部安全区，来源内容在剩余区域等比缩放、居中、不拉伸、默认不裁切。

页码支持底部居中和底部右侧，格式支持：

- `1`
- `— 1 —`
- `第 1 页`
- `1 / 50`

封面、目录可分别设置是否计入和显示；正文从用户指定数字开始，标题页属于正文。

## 8. 可靠性与错误

- 项目保存先写临时文件、刷新、Zod 重读，再原子替换并保留一代备份。
- 导出写同目录临时文件，重读校验后原子替换目标。
- 用户取消时停止后续页面，清理临时文件，不产生不完整目标。
- 缺失、加密、损坏、格式伪装、权限错误和非法页码范围不得静默忽略。
- 用户提示必须包含阶段、文件或材料、原因和建议；堆栈只写脱敏日志。

## 9. 性能目标

- 至少 300 个最终页面
- 输入文件合计至少 500 MB
- 缩略图按需加载和缓存
- Renderer 不持有大型二进制
- 后台导出期间 UI 保持可交互
- 大文件处理限制并发并支持取消

性能数字是设计目标，只有实际执行过的范围才记录为已验证。

## 10. 发布边界

提供 macOS DMG 和 Windows NSIS 配置。首版不要求签名和公证，但发布文档必须说明证书、Apple 公证和未签名应用警告。
