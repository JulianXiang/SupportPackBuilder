# PDF 处理流水线

## 1. 导入与检查

Main 使用文件对话框或由 preload 捕获的真实拖放路径。检查顺序包括：

1. 文件存在、普通文件、可读、非空。
2. 扩展名白名单。
3. `file-type` 检测真实 MIME，拒绝格式伪装。
4. SHA-256、大小和修改时间。
5. PDF 重读、页数和加密状态。
6. 图片尺寸、格式和 EXIF 方向。
7. 文件哈希、大小和原始文件名重复检查。
8. 用户选择导入、跳过或替换。

copy 模式先复制到 `assets/*.tmp`，成功后原子改名；reference 模式保存绝对路径。

## 2. 页面范围与编辑

页码表达式是纯函数，界面为 1-based，内部来源索引为 0-based。`all`、单页、区间和组合会得到有序去重结果。中文逗号、空段、0、负数、倒序、越界、小数和不完整区间是错误；空格和重复页产生警告。

页面编辑使用 `${sourceId}:${sourcePageIndex}` 作为稳定 ID。旋转、删除和排序只写 `project.json`。

## 3. A4 布局

A4 由 210×297 mm 和 72 point/inch 统一计算。默认边距：

- 上 36 pt
- 下 36 pt
- 左右 36 pt

PDF 页读取 CropBox、页面尺寸和 Rotate；来源旋转与用户旋转相加。通用矩阵将四个方向的内容等比缩放到安全区并居中。

当 PagePlan 为内容页提供 `inlineHeadings` 时，先按实际字体宽度完成中文换行并预留顶部高度，再把来源 PDF 或图片缩放到剩余安全区。一级标题使用约 22 pt，二级和材料标题使用较小粗体；标题过长导致正文区域不足时明确阻止导出，不裁掉标题或材料。

图片先由 Sharp 自动纠正 EXIF、转 sRGB、使用白色背景，再按屏幕 120 dpi、标准 180 dpi或高质量 300 dpi 档位嵌入。低分辨率图片不会静默放大而不提示。

## 4. 正式页面

封面、目录和标题页由隐藏 BrowserWindow 加载本地 React 页面。打印参数固定为 A4、优先 CSS 页尺寸、打印背景。参考版式使用宋体优先的中文回退链，并捆绑 OFL 字体。

封面标题为黑色正式样式并保留细蓝色上下边线。封面背面空白页由 PagePlan 和 worker 直接生成，不依赖打印窗口。目录默认标题为“支撑材料目录”，使用黑色多级缩进和点引导线。

## 5. 目录迭代

1. 假设目录为 1 页。
2. 构建 PagePlan 和逻辑页码。
3. 使用实际 TOC 条目生成目录 PDF。
4. 用 pdf-lib 读取实际目录页数。
5. 页数变化则更新假设并重算。
6. 最多 5 次；不稳定时删除临时目录并阻止导出。
7. 稳定后生成 canonical PagePlan。

目录材料页码指向材料标题页；没有标题页时指向第一内容页。

## 6. 后台合并

Main 准备生成页后启动 utilityProcess。worker 按 PagePlan 顺序：

1. 复用当前来源 PDF，避免重复打开同一文件。
2. 把生成页、PDF 内容页或图片页放入新的 A4 页面。
3. 绘制 PagePlan 指定的同页分级标题，并在重新计算的正文安全区内放置材料。
4. 在正文安全区下方绘制页码，参考格式为 `— 1 —`。
5. 写入 Title、Author、Subject、Creator、Producer 和日期元数据。
6. 写入 `/SPackPageId`、`/SPackPageType`、`/SPackInlineHeadings` 和页码文本标记。
7. 保存到与目标同目录的临时文件。

每处理一页发送小型结构化进度。取消标记在阶段和逐页循环中检查；超时后 Main 可终止子进程。

## 7. 输出校验

临时 PDF 会被重新打开并检查：

- 文件非空且可解析
- 实际页数等于 PagePlan
- 每页尺寸为目标 A4
- 页面标记顺序与计划一致
- 打印页码标记数量一致
- 打印页码文本、同页标题标记与 PagePlan 一致
- 页面 ID 不重复
- 启用材料没有遗漏
- TOC 条目与节点/材料起始逻辑页一致

全部通过后原子替换目标 PDF，JSON 报告保存到项目 `output`。失败或取消会清理临时文件并保留原目标。

后台中文标题与页码使用 SupportPack Sans SC 静态 TTF 完整嵌入。fontkit 对大字符集字体执行子集化时会出现漏字，因此这里有意不使用子集；来源、生成方式和哈希记录在 `THIRD_PARTY_LICENSES.md`。
